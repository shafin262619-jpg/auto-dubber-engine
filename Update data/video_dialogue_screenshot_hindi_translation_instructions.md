# নির্দেশনা: ভিডিও ডায়লগ স্ক্রিনশট + হিন্দি অনুবাদ (Reusable Workflow)

এই ফাইলটি একটি সম্পূর্ণ, পুনঃব্যবহারযোগ্য (reusable) instruction। প্রতিদিন ভিন্ন ভিন্ন গল্প/ভিডিও নিয়ে কাজ করার জন্য এটি যেকোনো নতুন Claude conversation-এ কপি-পেস্ট করে দাও অথবা upload করে দাও। Claude এই instruction পড়ার সাথে সাথেই নিচের কাজ শুরু করবে।

---

## Claude-এর জন্য নির্দেশনা (এখান থেকে শুরু)

তুমি নিচের workflow টি ধাপে ধাপে অনুসরণ করবে। প্রতিদিন ভিন্ন ভিন্ন ভিডিও/গল্প (short drama script) দিয়ে এই একই workflow চালানো হবে, তাই কোনো নির্দিষ্ট গল্পের content বা সংখ্যার (যেমন dialogue সংখ্যা, video length) উপর নির্ভর করবে না — যা ইনপুট আসবে তার উপর ভিত্তি করেই কাজ করবে।

### ধাপ ০: ইনপুট ফাইল চাও

কাজ শুরু করার আগে ব্যবহারকারীর কাছে নিচের দুটি ফাইল চাও (যদি ইতিমধ্যে দেওয়া না থাকে):

1. **ভিডিও ফাইল** (.mp4 / .mov ইত্যাদি)
2. সেই একই ভিডিওর **সাবটাইটেল ফাইল** (.srt), যাতে প্রতিটি ডায়লগের timestamp ও টেক্সট থাকে

দুটো ফাইল না পাওয়া পর্যন্ত পরের ধাপে যাবে না।

### ধাপ ১: ভিডিও ও SRT যাচাই করা

- `ffprobe` দিয়ে ভিডিওর duration চেক করো, ফাইলটা ঠিকমতো readable কিনা নিশ্চিত করো।
- SRT ফাইলটি পড়ে দেখো এবং তাতে থাকা টেক্সট এনকোডিং ঠিক আছে কিনা (mojibake / গার্বেজ ক্যারেক্টার না থাকে) যাচাই করো। যদি ব্যবহারকারী পরে চ্যাটে SRT-এর টেক্সট paste করে এবং সেটা mojibake দেখায়, তাহলে upload করা আসল `.srt` ফাইল থেকে সরাসরি clean UTF-8 টেক্সট ব্যবহার করবে, chat-এ paste করা garbled টেক্সট নয়।

### ধাপ ২: SRT পার্স করা

SRT ফাইলটি পার্স করে প্রতিটি dialogue block থেকে বের করো:
- ক্রম নম্বর (index)
- শুরুর timestamp (সেকেন্ডে রূপান্তর করে)
- ডায়লগের সম্পূর্ণ টেক্সট (multi-line হলে join করে একলাইনে আনো)

```python
import re

with open('subtitle.srt', 'r', encoding='utf-8') as f:
    content = f.read()

blocks = re.split(r'\n\s*\n', content.strip())
entries = []
for block in blocks:
    lines = block.strip().split('\n')
    for i, line in enumerate(lines):
        m = re.match(r'(\d{2}):(\d{2}):(\d{2}),(\d{3})\s*-->', line)
        if m:
            h, mi, s, ms = map(int, m.groups())
            t = h*3600 + mi*60 + s + ms/1000.0
            text = ' '.join(lines[i+1:]).strip()
            entries.append({'idx': int(lines[0]), 'time': t, 'text': text})
            break
```

### ধাপ ৩: প্রতিটি dialogue-এর শুরুর timestamp থেকে screenshot নেওয়া

প্রতিটি entry-র `time` (শুরুর timestamp) ব্যবহার করে ffmpeg দিয়ে একটি করে ফ্রেম extract করো:

```bash
ffmpeg -y -ss <timestamp_in_seconds> -i video.mp4 -frames:v 1 -q:v 2 output.jpg
```

### ধাপ ৪: প্রতিটি screenshot-এর নামে সংশ্লিষ্ট ডায়লগ বসানো

ফাইলের নাম হবে: `{ক্রম_নম্বর}_{sanitize_করা_ডায়লগ_টেক্সট}.jpg`

Sanitize করার নিয়ম:
- যদি SRT-তে কোনো transcription-tool watermark/boilerplate থাকে (যেমন "Transcribed by TurboScribe...") — সেটা বাদ দাও, এটা আসল ডায়লগ নয়।
- ফাইলসিস্টেমে নিষিদ্ধ ক্যারেক্টার বাদ দাও: `\ / : * ? " < > |`
- একাধিক space/whitespace একটাতে নামিয়ে আনো এবং trim করো।
- টেক্সট বেশি লম্বা হলে ~৬০ ক্যারেক্টারে ছোট করো (যাতে filename অতিরিক্ত লম্বা না হয়)।

```python
def sanitize(text):
    text = re.sub(r'\(Transcribed by TurboScribe.*?\)\s*', '', text)
    text = re.sub(r'[\\/:*?"<>|]', '', text)
    text = re.sub(r'\s+', ' ', text).strip()
    return text[:60]
```

### ধাপ ৫: সব screenshot একটি Zip ফাইলে বানানো

```bash
zip -r output_screenshots.zip screenshots_folder/
```

এই zip ফাইলটি `present_files` দিয়ে ব্যবহারকারীকে দেখাও।

### ধাপ ৬: সম্পূর্ণ স্ক্রিপ্ট জোড়া দিয়ে হিন্দিতে অনুবাদ করা

- সব dialogue entry-র টেক্সট (watermark/boilerplate বাদ দিয়ে) ক্রমানুসারে জোড়া দিয়ে একটি continuous script বানাও।
- এই সম্পূর্ণ গল্পটিকে স্বাভাবিক, প্রবাহমান (flowing) হিন্দি গদ্যে অনুবাদ করো — শুধু শব্দ-অনুবাদ নয়, বরং একটি সুখপাঠ্য গল্প হিসেবে।
- মূল টেক্সট যদি auto-transcription (ASR) থেকে আসা হয়, তাহলে তাতে সাধারণ homophone ভুল থাকতে পারে (যেমন উচ্চারণে কাছাকাছি কিন্তু ভুল শব্দ বসে যাওয়া)। প্রসঙ্গ বুঝে সেগুলো সঠিক অর্থে অনুবাদ করো, যাতে হিন্দি টেক্সট অর্থপূর্ণ ও স্বাভাবিক হয় — প্রতিটি ভুল আলাদা করে highlight করার দরকার নেই।
- একই চরিত্রের নাম যদি মূল টেক্সটে বিভিন্নভাবে লেখা থাকে (transcription ভিন্নতার কারণে), অনুবাদে পুরো গল্প জুড়ে একটি সামঞ্জস্যপূর্ণ (consistent) নাম ব্যবহার করো।
- গল্পটিকে দৃশ্য/scene অনুযায়ী স্বাভাবিক প্যারাগ্রাফে ভাগ করো, যাতে পড়তে সহজ হয়।
- এই অনুবাদটি একটি `.md` ফাইল আকারে তৈরি করো এবং `present_files` দিয়ে ব্যবহারকারীকে দেখাও।

### ধাপ ৭: চূড়ান্ত আউটপুট

প্রতিটি রানে ব্যবহারকারী দুটো ফাইল পাবে:
1. **Screenshots ZIP** — প্রতিটি ডায়লগের শুরুর মুহূর্তের ছবি, ফাইলনামে সেই ডায়লগ লেখা
2. **হিন্দি অনুবাদ (.md)** — সম্পূর্ণ গল্পের প্রবাহমান হিন্দি সংস্করণ

---

## ব্যবহারকারীর জন্য নোট

- প্রতিদিন নতুন ভিডিও + নতুন SRT ফাইল দিলে একই workflow আবার চলবে, গল্প যাই হোক না কেন।
- যদি ffmpeg/ffprobe না থাকে বা network/tool সীমাবদ্ধতা থাকে, Claude সেটা জানিয়ে দেবে।
- অতিরিক্ত কিছু (যেমন timestamp অনুযায়ী হিন্দি .srt সাবটাইটেল ফাইল) চাইলে সরাসরি বলতে হবে, এটা এই instruction-এর default অংশ নয়।
